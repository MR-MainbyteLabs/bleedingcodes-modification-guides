# BleedingCodes Modification Guides

Architecture, extension points, and safe modification patterns for every tool in the
[BleedingCodes](https://github.com/BleedingCodes) repository.

Each guide covers the actual class names, function names, and data structures from the source —
where to make each class of change, what not to touch, and working code examples for common modifications.
